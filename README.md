# Study Agent

一个由**桌面**和**助理**组成的学习软件。桌面放文件、显示任务；助理根据你的要求整理材料、组织练习、回答问题。打开文件后，可以一边阅读、一边划词提问。

当前已接通真实文件存储、学习服务和 DeepSeek Harness，并在隔离数据上验证。**还不是已经公开上线的产品**：云端托管、登录与访问控制、运行凭据和备份运维仍需落实。本项目目前只在云端开发并更新 GitHub，不安排本机部署，也不再次测试真实 DeepSeek 推理。

## 使用方式

第一次使用，可以放入材料，也可以直接告诉助理想学什么。不必先完成学期规划或填写课程配置。助理读取实际材料，建立需要的课程入口，再与你核对当前工作需要的信息；不知道的范围和进度保持未知。

桌面以文件夹为主，另有真实任务清单。文件在标签页中打开，可并排查看。支持 Markdown、LaTeX、文本、PDF、常用图片和音频；文件上限 20 MB。PDF 支持翻页、缩放和文字选区；扫描件没有文字层时不假装能划词，目前没有 OCR。

助理保存生成的文件、题目和原始作答。任务勾选表示用户确认完成，不表示掌握知识。批改、错点与复测必须有真实作答依据。阅读、练习和提问可以自由切换，没有预设学习路线或先后顺序。

LaTeX 可以编辑和编译为 PDF。编译失败保留上一版成品；正式笔记和练习须保存写作依据，并读取实际页面核对来源与版式。编译成功不等于核验通过。

## 记忆、课程与学期

助理按实际适用范围保存信息，不把所有东西都当成“学期状态”。

| 信息 | 保存范围 | 换学期后的处理 |
| --- | --- | --- |
| 通用沟通习惯、讲解偏好、学习习惯 | Agent 整体记忆 | 保留，供以后沟通参考 |
| 根据用户意愿判定适合通用的模型服务流程 | 学期之外的通用流程 | 保留；当学期或课程例外仍可单独设置 |
| 一门课的要求、方法、进度、考核与错点 | 当前学期中的课程 | 留在旧课程，不自动复制 |
| 明确只限本学期的安排 | 当前学期 | 不自动带入新学期 |
| 当前提问或本次临时要求 | 当前对话或任务 | 不擅自升级成长期约定 |

**记忆是参考，不是命令或许可。**助理应用记忆时结合当前材料、用户要求和当下意愿；需要改变安排而意愿不明时再沟通。当前明确要求优先，不因旧习惯自动布置练习、创建任务或调整流程。范围不明不擅自设定有效期。

可以直接请助理整理、结束或准备下一学期；助理可自主判断资料与约定的去留，保留来源、原件和恢复能力，也能在处理结束后切换学期。页顶“学期”入口用于新建、切换、重命名、归档、下载备份和可恢复的移除，不是必须完成的设置向导。归档保留文件、对话、作答、历史和未完成任务，进入查看状态；需要修改或继续提问时可以重新开始。处理尚未结束时拒绝切换，旧页面请求不会写到新学期。

新学期从独立的课程、文件、任务、对话和学习状态开始；整体记忆和通用模型流程仍在。移除旧学期不清除整体记忆。文件也可从桌面移除并恢复；已关联的课程原件、证据和任务不随之删除。需要复用旧课程资料时，助理可根据目标自主选择并说明依据，不迁入旧任务身份、日期或掌握结论。

目前的移除是**可恢复移除**，没有永久删除入口；学期备份是下载导出，没有上传备份恢复入口。外部自动化和定时提醒尚未接通，不能声称归档已经取消外部系统里的提醒。

## 仓库结构

这是一个产品。应用核心、学习业务和第三方运行引擎按职责组织，不是三套并行系统。

```text
study-agent              唯一启动入口
packages/
  agent/                 助理工具、流程、整体记忆、文件存储与 Web 服务
  learning/              学习领域服务：任务、材料、批改、复测、交付与质量标准
ui/                      桌面、文件阅览与对话界面
scripts/                 依赖准备和统一检查
verification/            浏览器及上游接入验证
vendor/deepseek-harness/  固定版本第三方运行引擎
```

`packages/agent/` 把用户要求交给模型，并调用 `packages/learning/` 保存与核对学习事实；第三方引擎负责模型循环和会话。学习包的源码直接位于 `src/study_agent/`，没有旧应用里再嵌套一层应用的目录。`skills/`、工具和领域检查留在学习包内，靠近所规范的业务。个人资料位于运行时指定的独立目录，不混在源码中。

结构参考了 [Codex 的组件划分](https://github.com/openai/codex/blob/main/codex-rs/Cargo.toml)、[OpenCode 的 packages 组织](https://github.com/anomalyco/opencode/blob/dev/package.json)和 [DeepSeek Harness 的应用与核心分层](https://github.com/deepseek-ai/deepseek-harness/blob/master/pnpm-workspace.yaml)。只采用职责清楚的划分，不引入它们的大型仓库规模。

## 实现与数据

固定采用 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的 [`5badb15009ae1756c3afe0ae0cef1faafc290ccc`](https://github.com/deepseek-ai/deepseek-harness/tree/5badb15009ae1756c3afe0ae0cef1faafc290ccc)（`0.2.1-alpha.1`）。复用它的模型循环、会话、工具和附件能力；`packages/learning/` 中已有的任务、材料、批改、复测、计划和交付服务提供学习账本。没有另写一套模型循环。

模型可以读取、执行和修改实际流程；修改经过验证才生效，保留旧版本和在途证据。通用流程与当学期、课程例外分开；流程规范模型检查材料、保存依据和核验结果，不规范用户必须怎样学习。生成代码属于可信单用户扩展，不是任意代码的安全隔离环境。

维护者指定的 `--data` 是整个学习空间：

- 首个学期兼容原数据位置；新学期在 `.semesters/<身份>/` 下，各自保存课程目录、文件版本、原始作答、SQLite 账本及 Harness 会话。
- `.semesters/agreements.json` 保存 Agent 整体记忆；`.semesters/shared/` 保存通用流程。它们在所有学期之外。
- 每学期 `.study-system/agreements.json` 保存课程与明确限期的约定；`COURSE.md` 是课程入口，实际来源通过明确的课程关联进入原材料服务。
- `.workspace/` 保存不可变文件版本；`.study-system/` 保存原领域状态；`.harness/` 保存模型会话。重命名和移动保持文件身份，修改保留历史，冲突不覆盖原文。
- 原服务的记忆文档作为当学期的已有记录保留，不自动把旧文档全部提升成整体记忆。助理只依据用户意愿将明确的通用偏好保存到整体记忆。

程序、凭据与个人学习数据分离。真实课程材料、作答、数据库和密钥不提交 GitHub，不读取或迁移原自用 Study System 的真实数据。备份导出包括学期文件和一致的 SQLite 副本，排除其他学期、整体记忆、模型内部缓存、临时编译目录及凭据；它不是完整托管环境的灾难恢复方案。

助理运行约定在 [packages/agent/ASSISTANT.md](packages/agent/ASSISTANT.md)，由插件直接加载并结合当前记忆提供给模型。开发工作约定在 [AGENTS.md](AGENTS.md)。正式笔记与练习的质量标准继续使用 `packages/learning/skills/`，历史本机模型分工由当前助理的云端工具承担。

## 云端运行与检查

维护者准备 Python 3.9+、Node 24、pnpm、XeLaTeX、latexmk、中文宏包（ctex/Fandol）和 Poppler。Linux 通常需要 `texlive-xetex`、`texlive-lang-chinese`、`latexmk`、`poppler-utils`。

```bash
./study-agent setup
./study-agent web --data /path/to/independent-study-data --port 8765
```

Web 服务只监听 `127.0.0.1`，供一个可信用户的独立云端空间使用。公开访问需要托管平台适配反向代理、登录与访问控制；目前不是公共多用户服务。模型凭据由云端 `DEEPSEEK_API_KEY` 等上游配置提供，网页不接收密钥。默认图像路由为上游声明的 `deepseek-flash`；其他路由由维护者明确配置。

`./study-agent serve --data ROOT` 是 SDK 入口，`./study-agent service --data ROOT` 是原学习服务的兼容入口；它们直接针对选定学期，维护者使用，不是学生使用向导。Web 的学期选择不会替这些独立进程切换目录。

```bash
./study-agent check
node verification/ui/check.cjs
```

检查使用临时学习空间和脚本化模型响应，覆盖实际 SDK 工具调用、持久状态、流程修改、中文 PDF 编译与页面读取，以及浏览器上传、划词、作答、停止和重启。生命周期检查覆盖课程建立、整体记忆保留、课程信息隔离、通用流程与本学期例外、归档、移除恢复、备份以及切换期间的旧请求拒绝。它们不证明真实模型的教学质量或视觉判断能力，也不发送真实 DeepSeek 推理请求。

上游完整 monorepo 构建尚未验收；依赖准备排除本项目未使用、当前网络无法获取的 SheetJS 文档预览包，保留上游锁文件。项目 PDF 阅览采用同版本 PDF.js 及官方文字层。macOS Calendar 属可选能力，Linux 如实报告不可用。

## 距离第一版发布

当前适合进入**可信单用户云端试用**的准备阶段。首次使用、日常反馈、信息范围和学期交接已有实现；仍有以下发布工作：

1. 确定托管方式，完成实际访问入口、登录保护、凭据配置和运行依赖。
2. 落实托管数据的备份、恢复演练与用户明确的永久删除政策；当前导出和可恢复移除不能替代这些工作。
3. 在目标托管环境确认浏览器、编译与中断恢复，并检查 GitHub Actions 结果。现有隔离验证不等于生产环境验收。

不要求重新进行用户已经完成的 DeepSeek 使用测试，也不把 OCR、多用户协作或复杂学期仪表盘设为这一版必备。

## 本次三轮使用流程审查

三轮均为开发中的角色代入与隔离场景检查，并非三名真实用户的独立评测。

| 视角 | 发现与已完成修改 |
| --- | --- |
| 首次使用者 | 建课不再依赖模型自行拼装命令；课程入口保持未知、没有预建计划。修正刷新后文件夹编号复用与上传失败仍称成功的问题。 |
| 学期中改变想法的用户 | 整体习惯不再困在学期数据里；课程与临时要求不自动升级成通用记忆。记忆作为参考提供，当前意愿优先；通用流程保留课程和当学期例外。 |
| 结束与换学期的用户 | 学期数据隔离，旧请求不能写新学期；归档不伪造完成。移除可恢复、整体记忆保留，重复移除不会破坏恢复状态；编译不阻塞状态查看和停止，课程文件同步进行并发检查。 |

当前隔离检查：原领域 208 项（207 通过、1 跳过），项目流程与生命周期 45 项通过，上游定向及融合循环 221 项通过；浏览器检查另覆盖真实上传、SDK 操作、PDF、作答、记忆保存和学期交接。真实模型的沟通与判断仍不能靠这些检查保证。
