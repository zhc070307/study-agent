# Study Agent

**一个放学习文件的桌面，和一个帮你整理、练习、答疑的助理。**

把课件、笔记、题目和课堂资料放进来，用自然语言告诉助理你需要什么。打开文件后可以边看边问，也可以选中文字直接提问。阅读、练习和提问没有固定顺序，由你决定。

![桌面与助理](ui/previews/desktop.png)

目前是面向个人使用的试用版本。资料保存在运行软件的电脑中；向助理提问时，所需文字和页面可能发送到你配置的 DeepSeek 服务。录音转写按需启用，在本机运行，不将录音发送给 DeepSeek。

## 先把软件打开

macOS 和 Windows 使用 **Docker Desktop** 安装，中文 LaTeX、PDF 工具和运行依赖随软件一起准备，不需要另装 Python、Node 或 TeX Live。Windows 请使用 Docker Desktop 的 Linux 容器模式；Apple Silicon 使用 x86_64 模拟运行，速度可能较慢。

1. 安装并打开 [Docker Desktop](https://www.docker.com/products/docker-desktop/)。Windows 首次设置可能需要启用 WSL 2 并重启电脑。
2. 下载本仓库并解压，或使用 Git 克隆。在这个文件夹中，将 `.env.example` 复制为 `.env`，填入自己的 `DEEPSEEK_API_KEY`。它用于助理回答问题，需要可用的 DeepSeek API 账户及余额；不要将密钥发到聊天、截图或 GitHub。Windows 请确认文件不是 `.env.txt`。
3. 在这个文件夹打开终端，运行（先创建可选工具的连接目录）：

```bash
mkdir .local-tools
docker compose up --build -d
```

首次运行需要联网下载依赖，可能需要几分钟，并占用数 GB 磁盘。完成后在浏览器打开 **http://localhost:8765**。此地址只供这台电脑访问。

查看启动情况：`docker compose logs --tail=50 study`。停止使用：`docker compose stop`；再次打开：`docker compose up -d`。更新代码后重新运行安装命令即可，学习数据保存在独立存储中。**不要删除 Docker 的学习数据卷，也不要用 `docker compose down -v` 更新软件。**

## 第一次打开：从一门课开始

空桌面是正常的，不需要先建完整学期计划。

你可以先对助理说：

> 这是我这学期的微积分课。我想让你帮我整理资料、解释问题和组织练习，先不要给我排固定学习计划。

助理可以建立课程文件夹。也可以自己点击桌面上的“新建文件夹”，用课程名称命名。打开对应文件夹，点击“添加文件”，或将文件拖到里面。还没想好归哪门课的资料可以先放在“未整理”，之后请助理整理。

建议先放课程大纲、考核说明和已有材料。告诉助理它们属于哪门课、你已经学到哪里、当前想做什么；不知道的内容可以留待以后。单纯创建文件夹不等于助理已经读过资料，上传后需要向助理提出要求，例如：

> 我刚放入课程大纲和第一讲课件。请先读材料，帮我整理到这门课；说明哪些信息还不知道，不要推断我已经学完。

不需要理解内部工具，也不用按模板填写学习方法。

## 每次课前和课后怎么用

有新课件、教师笔记、讲义、题单、课堂手写笔记或作业要求时，收集后放进**对应课程文件夹**。文件名可以带日期或课次，方便你辨认；有用的原文件保留，不必为每节课另建一套目录。

课前，你可以上传已拿到的材料并说：“帮我解释这一讲的背景”或“我想先看看这些题”。课后，告诉助理本次实际讲到哪里、哪些地方没听懂，再提出当前需求。例如：

> 这是今天的课件和我的课堂笔记，老师讲到链式法则。请结合这些资料整理一份能读懂的笔记，保留必要推导，不附练习题。

> 不用先整理笔记。请从已经讲过的内容中选两道题，我做完再请你批改。

**不要求每节课录音，也不要求每次都生成 PDF。**如果你选择录音，先确认课程允许、相关人员同意。录音也放在课程文件夹；打开后可以“转写”，或者直接对助理说“把这份录音转成文字”。转写原稿会保存为同一文件夹中的文本，之后可请助理结合课件整理笔记。自动识别可能听错术语、数字和公式，重要内容需结合原录音和课程材料核对。

转写是可选能力，已有文字稿直接上传即可。**默认优先 GPU，不会自动退回 CPU。**首次需要时按下面的“可选：录音转写”启动本机后台，检测通过、你确认后才下载环境与约 3.8 GiB 模型。它没有独立界面，仍在 Study Agent 中操作。

## 可选：录音转写

普通文件阅读、问答、笔记和练习不需要以下安装。Docker 中的程序无法使用 Mac 的 Metal；转写后台在你自己的电脑上运行，以调用本机 GPU。

1. 安装 [Python 3.12](https://www.python.org/downloads/)；Windows 勾选 Python Launcher，Mac 使用官方安装包。
2. 在项目的 `scripts` 文件夹中，Mac 双击 `transcription-mac.command`，Windows 双击 `transcription-windows.bat`。若 Mac 不允许双击，可在项目目录运行 `bash scripts/transcription-mac.command`。
3. 保留后台窗口，回到 Study Agent 打开录音并点击“转写”，或告诉助理你需要转写。程序先检查资源，再询问是否下载；原稿保存到录音所在文件夹，原录音保留。

| 默认加速方式 | 下载前的最低检查条件 |
| --- | --- |
| Apple Silicon / Metal | macOS 14+，实际可用统一内存 8 GiB，首次空闲磁盘 10 GiB |
| Windows/Linux x64 / NVIDIA | 支持 CUDA 12.8 的驱动，可用显存 6 GiB、可用内存 6 GiB，首次空闲磁盘 18 GiB |

另需至少 2 GiB 临时空间。CUDA 环境较大，磁盘需求包含依赖与模型；这些是保守的容量检查，不能保证某台设备的速度或所有录音都能处理。Apple 建议 16 GB 以上内存，NVIDIA 建议 8 GB 以上显存。后台还会在下载模型前用实际运行环境验证 GPU；验证失败就停止，不悄悄改用 CPU。当前未支持 Intel Mac、AMD/Intel 显卡加速。

没有受支持 GPU 时不自动下载。你确实愿意等待较慢的 CPU 转写时，可在项目目录运行 `python3.12 packages/transcription/host.py --cpu`（Windows：`py -3.12 packages/transcription/host.py --cpu`）；需至少 12 GiB 实际可用内存和首次 10 GiB 空闲磁盘。首次网络需能访问 PyPI、PyTorch 和 Hugging Face。关闭后台窗口会中断转写，下次启动后可继续已完成的片段。

后台的连接凭据保存在项目的 `.local-tools`，不要分享该目录；音频只传到这台电脑的转写后台。它不是给公网开放的服务。若防火墙提示，按本机 Docker 连接需要允许访问，勿开放公网。学习文件在 Docker 数据卷，转写环境与断点在用户目录的 `.study-agent/transcription`，二者都不会进入源码仓库。

## 看文件、提问和做练习

点击文件即可打开，旁边的对话框保留。可以直接问整份文件，也可以选中文字后点“提问”；PDF 支持翻页、缩放和文字选区。扫描件没有文字层时无法划词，当前没有 OCR。

生成的笔记、练习和 PDF 会出现在桌面。练习可填写并保存作答，再请助理批改；原答案和后续反馈保留。任务清单只展示实际需要做的事情，勾选表示你确认完成，不代表系统认定你已经掌握。

如果安排不合适，直接说：“这次只解释”“题量减半”“别把我的临时要求记成长期习惯”。助理可以据此调整，通用偏好只作沟通参考，当前意愿优先。

## 一个学期结束之后

页顶“学期”入口可以新建、切换、重命名、归档、下载学期备份和可恢复地移除；也可以请助理处理。归档保留文件、对话、作答和未完成任务，需要继续时可重新开始。

新学期的课程、文件、任务和学习记录分开保存。通用沟通与学习偏好留在学期之外，供以后参考；旧课的进度、日期、错点和掌握结论不会自动带过去。需要沿用某些旧资料时，告诉助理你想保留哪些内容，或请它按新目标整理。

当前移除可以恢复，不是永久删除。界面的学期备份不包含整体记忆与完整运行环境，也没有备份导入入口；重要资料请另行保留原件，卸载 Docker 或清除数据卷前先备份整个学习存储。

## 支持哪些文件

Markdown、LaTeX、文本、PDF、常用图片和音频。普通文件目前上限 20 MB；录音上限 200 MB，建议使用压缩音频格式。LaTeX 可编辑并编译为 PDF，失败时保留上一版；自定义文档使用额外宏包、专用字体或外部图片时，仍需提供这些依赖或改用已安装的写法。

当前用于一个可信用户。没有多人账户、云端同步、自动提醒或公开网络托管；不要将服务端口暴露到公共网络。助理可运行工具和修改流程，所以不要把它作为不受信任用户的共享服务。

## 打不开或处理失败

| 情况 | 怎么处理 |
| --- | --- |
| 安装命令找不到 Docker，或连接不到 Docker | 确认 Docker Desktop 已安装并启动；Windows 确认使用 Linux 容器。 |
| 首次下载失败 | 检查网络能访问 Docker、Debian、npm 和 Node 下载源，然后重试安装命令。 |
| 浏览器打不开 | 查看启动日志；确认 8765 端口没有被其他程序占用。 |
| 助理无法回答 | 检查 `.env` 中的密钥、API 余额及模型服务网络，修改后运行 `docker compose up -d --force-recreate`。 |
| PDF 编译失败 | 查看文件上的编译结果；额外宏包、字体或附件需补齐。旧 PDF 不会因失败被删除。 |
| 转写下载失败或内存不足 | 检查本机转写后台、GPU 驱动、Hugging Face/PyPI/PyTorch 网络，以及提示的可用内存、显存和磁盘；停止后可以继续，原录音保留。 |

维护者可运行 `docker compose run --rm --no-deps study python3 study-agent doctor --require-model --data /data`，检查中文宏包、实际编译、PDF 文字与页面读取、原生模块、模型配置和数据写入。检查不会调用模型，也不能证明 API 余额和网络可达。

## 项目与开发

应用核心在 `packages/agent/`，学习领域服务在 `packages/learning/`，界面在 `ui/`。有取舍地采用并自行维护的 DeepSeek Harness 运行实现放在 `packages/runtime/`，没有 Git 子模块或第二套应用入口。可选转写实现来自 LocalTranscribe，采用后台能力，不包含其 GUI。

Linux x86_64/glibc 维护者也可直接运行：准备 Python 3.9+、Node 24、pnpm 11.19.0 和系统依赖后执行 `./study-agent setup`，再用 `./study-agent web --data /独立学习目录` 启动。中文环境需要 XeLaTeX、latexmk、ctex/Fandol、常用 TeX Live 宏包与 Poppler，安装检查会提示缺项。开发检查为 `./study-agent check` 和 `node verification/ui/check.cjs`，使用临时资料和脚本化模型，不调用真实 DeepSeek。
