# Study Agent

一个放课程文件、与学习助理交谈的学习桌面。助理可以整理材料、解释问题、整理笔记、组织练习，并根据你的反馈调整安排。

![学习桌面](ui/previews/desktop.png)

## 下载与安装

当前是首轮用户测试版。可以直接下载下面的安装包，也可以打开[版本下载页面](https://github.com/zhc070307/study-agent/releases/tag/v0.1.0-beta.1)查看版本说明：

| 电脑 | 下载 | 安装方式 |
| --- | --- | --- |
| Apple 芯片 Mac，macOS 14 或更新 | [Mac 安装包](https://github.com/zhc070307/study-agent/releases/download/v0.1.0-beta.1/Study-Agent-0.1.0-macOS-arm64.dmg) | 打开 `.dmg`，将 Study Agent 拖到“应用程序”，再打开它。 |
| Windows 10（1903 或更新）/ 11，64 位 Intel 或 AMD 电脑 | [Windows 安装包](https://github.com/zhc070307/study-agent/releases/download/v0.1.0-beta.1/Study-Agent-0.1.0-Windows-x64.exe) | 打开 `.exe`，按安装向导完成，然后从开始菜单或桌面打开。 |

版本下载页面中，`Source code` 是源码；安装软件请选择 `.dmg` 或 `.exe`。

目前不提供 Intel Mac 或 Windows ARM 安装包。应用已包含运行组件、PDF 阅读工具和常用中文 LaTeX 宏包，无需自行安装 Python、Node、TeX 或 Docker。普通学习功能使用在线助理，不要求电脑有独立显卡，也不下载本地大模型。

安装包包含排版组件，安装可能需要几分钟，请等安装向导完成后再打开。卸载应用会保留学习资料；重要内容仍建议先下载学期备份。

测试版还没有正式发行者签名与 Apple 公证，系统可能提示无法验证发行者。只在确认安装包来自本项目维护者后继续：Mac 可在“系统设置 → 隐私与安全性”中允许打开；Windows 若显示“更多信息 → 仍要运行”，可在核对来源后使用。无需关闭电脑的整体安全保护。

首次打开会提示填写 [DeepSeek 服务密钥](https://platform.deepseek.com/api_keys)。模型服务可能产生费用，由你的 DeepSeek 账户承担。可以先取消，阅读文件或手动整理；之后随时在“设置”中填写。密钥只保存在当前电脑的私有设置中，不包含在学期备份里。

资料、作答和学习记录保存在电脑上。与助理交谈时，问题和它处理所需的相关材料会发送给 DeepSeek；录音识别在本机进行，得到的文字稿在交给助理处理时也可能发送给 DeepSeek。请助理整理、回答或制作材料时需要联网；已保存文件可以直接阅读，手动整理不需要联网。

## 从空桌面开始

告诉助理你的学期和课程，例如：“这是我的秋季学期，我有微积分、线性代数和物理三门课。”也可以点击桌面的“＋”创建课程。

把收集到的课件、讲义、作业、课堂文字稿或录音拖进桌面，或点击“添加文件”。新文件先放在桌面的待整理区域，你不用先寻找文件夹。请助理整理，它会结合材料内容和你的说明，将文件放到合适的课程里；归属不清楚时会与你确认。

每门课都有课程资料、笔记、练习和作业文件夹，也可以根据实际需要增加或调整分类。生成的笔记和练习保存在相应课程的分类文件夹中。助理的内部规则与记忆不会混在这些学习文件里。

例如，先把三份课件直接拖进桌面，再说：“请把它们整理到微积分，帮我解释第二份里积分换元的部分。”不必先设置一整套学习流程；遇到问题就打开材料、选中文字或直接提问。

## 日常怎么用

课前可以放入课件、讲义和已有的问题，让助理帮助准备；课后可以补充课堂资料、文字稿和自己的想法，让助理帮你梳理。有现成文字稿就直接使用，无需录音或安装转写工具。这些都是可选方式，不要求每节课录音，也不规定阅读和练习的先后顺序。

打开文件后，右侧就可以围绕它提问。阅读 Markdown 或 PDF 时可以选中文字，再点“问助理”；也可以同时关联多个文件。练习页面支持保存作答并带着作答讨论。

任务清单按课程分组，可以查看今天、接下来的安排或全部任务，也能筛选某门课程。完成的事项收在“已完成”中。你可以直接告诉助理：“这周时间少一点”“这部分已经掌握”“先练习再看笔记”，让它与你商量后调整。

## 录音转写

录音转写是可选功能。桌面应用会管理本机转写服务，无需单独打开另一个软件。打开录音，点击“转写”，先检查设备的显卡、实际可用内存和磁盘空间；设备适合且你同意时，才下载推理组件和约 3.8 GiB 模型，不会默认改用 CPU 转写。

首次安装的设备检查要求如下；这里的内存与显存指当时空闲的容量，不是电脑标称总容量：

| 加速设备 | 可用内存 | 可用显存 | 空闲磁盘 |
| --- | --- | --- | --- |
| Apple Silicon 的 Metal | 至少 8 GiB | 使用统一内存 | 至少 10 GiB |
| NVIDIA 显卡 | 至少 6 GiB | 至少 6 GiB | 至少 18 GiB |

两种设备都还需要至少 2 GiB 临时空间。NVIDIA 驱动需要支持 CUDA 12.8，Windows 检查门槛为 570.65。下载需要连接组件与模型的下载服务；网络失败不会被显示为安装成功，可以稍后重试。通过设备检查只代表资源满足门槛，识别效果与速度仍需在测试用户的真实设备和录音上确认。

已有文字稿时直接交给助理即可，无需获取转写组件。

## 换学期与保留资料

在顶部学期菜单中创建新学期。不同学期的课程、文件、任务和对话分别保存；旧学期可以归档，需要时再打开。

某门课的要求应留在那门课中。可以跨学期使用的沟通偏好和学习习惯，由助理结合你的意愿决定是否保留。记忆只是帮助理解你的参考，你当前的要求优先。

你可以说：“归档这个学期，下学期继续沿用简洁讲解的习惯，课程进度重新开始。”助理可按你的要求整理保留的内容，说明主要取舍；不会把旧任务、旧日期或旧掌握情况当作新学期进度。

移除学习内容前，助理应说明涉及的资料；要求明确时直接处理，范围不清时再沟通。当前文件与学期移除可以恢复，**不等于永久删除**；当前版本不提供永久删除入口。可以在学期菜单下载备份，或恢复备份为一个独立学期；恢复不会覆盖现有学期和通用偏好。备份中旧的学习偏好交给助理作为参考，是否继续使用由你决定。备份完成后将下载的文件保存到另一处，重要原件也请另外保留。

## 支持的材料

支持 Markdown、LaTeX、文本、PDF、常用图片和音频。普通文件目前上限为 100 MB，录音为 200 MB。LaTeX 支持编辑和编译为 PDF；编译失败时保留上一版 PDF。使用特殊宏包、字体或外部图片的文档，还需要相应依赖和附件。
