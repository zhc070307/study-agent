# 导数：从变化开始

## 平均变化率

一段路程的平均速度，描述的是整个时间区间内的变化。如果想知道某一瞬间的速度，就需要把观察区间逐渐缩小。

对于函数 f，在 x 附近取一个增量 h。函数值的变化量除以自变量的变化量，得到区间的平均变化率：

```text
( f(x + h) − f(x) ) / h
```

## 瞬时变化率

当 h 趋近于零时，如果上述比值趋向一个确定的值，这个值就是函数在 x 处的导数：

```text
f′(x) = lim [ ( f(x + h) − f(x) ) / h ]
        h→0
```

**计算中 h 不等于零，不能直接把分母替换成零。**

## 几何解释

导数可以理解为曲线在该点的切线斜率，也可以理解为某个量在这一刻变化的快慢。

- 平均变化率描述一个区间。
- 瞬时变化率描述局部变化。
- 使用极限时，要保留定义所要求的条件。
